# 📌 주요 기능 및 구현내용


### 주요 기능
> - 로그인, 회원가입, 도서 정보 관리 (조회, 등록, 수정, 삭제)
> - 장바구니, 주문(쿠키 기반), 예외처리, 게시판(MVC), 웹 채팅, 은행 시스템 기능 포함
> - 사용자 중심 인터페이스 + 데이터 저장/ 불러오기
</br>

### 구현 내용
> - JSP/Servlet 기반 웹 구조 설계 및 구현 (Spring 미사용)
> - MVC 패턴 직접 설계하여 게시판 기능 안정성 향상
> - DB 설계 및 연동: 사용자/도서/주문정보 저장 및 조회 처리
> - Eclipse 개발 환경에서 WAR 파일 빌드 및 서버 배포 → 외부 사용자도 접근 가능한 웹사이트
> - 은행 시스템 및 실시간 채팅 기능 추가로 사용자 편의성 강화
</br>

# ✨ 성과 및 배운점
> - JSP 기반 웹 사이트 전체 구조 직접 설계 및 구현 경험
> - Spring 없이 MVC 패턴 구현 → 백엔드 구조 설계 능력 향상
> - 클라이언트-서버 간의 데이터 흐름 이해도 증진
> - 서버 배포 과정 학습 및 실습 경험 → 배포형 프로젝트 경험 확보
